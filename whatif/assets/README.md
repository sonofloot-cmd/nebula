Static files served to the video at render time.

- `music.mp3` (optional): background track, mixed at low volume. If the file is
  missing the video renders silent. An episode can point at a different file with
  `"music": { "file": "my-track.mp3" }`.
- `fonts/`: Playfair Display (hook/end card) and Inter (UI) — SIL Open Font License.
